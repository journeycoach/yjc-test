About Site Settings Changes here update the brand colors, typography, and call-to-action buttons across the entire site. The color and font choices apply globally via CSS variables — you don't need to update individual pages. After saving, the live site reflects your changes within seconds.
Brand Colors
Tip Use the color picker or type a hex value directly. The accent gold is your primary brand color — it appears on buttons, links, and highlights. Keep changes subtle to maintain the premium feel.
Typography
Tip These fonts must be available on Google Fonts. The heading font appears in titles and section headers. The body font is used for all paragraph text and UI elements. Changing fonts updates the entire site.
